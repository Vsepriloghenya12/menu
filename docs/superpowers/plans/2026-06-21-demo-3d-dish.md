# Demo 3D Dish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bundle one GLB dish and provide touch rotation and zoom from the tablet menu.

**Architecture:** An isolated Expo DOM component wraps `<model-viewer>`, keeping WebGL code outside the native menu. The existing tablet component owns modal visibility and exposes the viewer only for the demo dish.

**Tech Stack:** Expo SDK 56, Expo DOM components, React Native WebView, Google model-viewer, GLB.
